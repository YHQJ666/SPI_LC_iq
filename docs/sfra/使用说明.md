# SFRA 扫频使用说明

日期：2026-10-28
适用工程：`SPI_LC_iq`（F28035 单相离网逆变，20 kHz 开关频率）

## 一、两种模式，编译期二选一

| | OLED 版（默认） | SFRA 版 |
|---|---|---|
| `SFRA_ENABLE` | `0` | `1` |
| `SFRA_FLASH_BUILD` | `0` | `1` |
| 链接脚本 | `28035_RAM_lnk.cmd` | `28035_FLASH_lnk.cmd` |
| 程序在哪运行 | SARAM | **Flash**（SARAM 全留给数据） |
| 显示 | OLED 8 行 | 无（GPIO28/29 让给 SCI） |
| 示波器 | `ScopeIout` / `ScopeIL` | 同左（地址不同） |

### 切换步骤

1. 改 `APP/dcac_cfg.h` 里两个宏：`SFRA_ENABLE`、`SFRA_FLASH_BUILD`
2. CCS 里：Project → Properties → Build → C2000 Linker → File Search Path，
   把 **Linker command file** 在 `28035_RAM_lnk.cmd` / `28035_FLASH_lnk.cmd` 之间换
3. **Rebuild All**（不能只 Build，宏改了要全编）
4. **Load Program**，然后 Reset + Resume

> 两步必须一起改。配错组合的后果：
> - `SFRA_ENABLE=1` + RAM 脚本 → 链接报**溢出**（放不下），不会静默出错
> - `SFRA_ENABLE=0` + Flash 脚本 → 能跑，只是多走一遍 Flash 搬移

## 二、扫什么，靠 `LOOP_MODE` 决定

改 `APP/dcac_cfg.h` 的 `LOOP_MODE`，Rebuild All。

| `LOOP_MODE` | 物理状态 | 注入 | 采集 | 用来测 |
|---|---|---|---|---|
| `LOOP_SINE_OPEN` (0) | 正弦开环 + 软启动 | 无 | 无 | **正常逆变运行**（不扫频）|
| `LOOP_VOLT_CLOSED` (1) | 电压单环 | `Vref` | `Vout` | 电压环闭环增益 |
| `LOOP_CURR_CLOSED` (2) | 电流单环 | `Iref` | `IL` | 电流环闭环增益 |
| `LOOP_DUAL` (3) | 电压 + 电流双环 | `Vref` | `Vout` | 双环下电压环增益 |
| `LOOP_FIXED_DUTY` (4) | 固定占空比开环 | `Duty` | `IL` | **受控体 Plant** |

**测受控体（第一步）用 `LOOP_FIXED_DUTY`**，测环路增益用 1/2/3。

## 三、扫频时的直流工作点

单相逆变器的参考是 50 Hz 正弦，没有稳态工作点，所以 `SFRA_ENABLE=1` 时
参考被**冻结成直流**：

| 量 | 值 | 宏 |
|---|---|---|
| 电压环给定 | 20 V | `SFRA_VREF_DC` |
| 固定占空比 | 0.4 | `SFRA_DUTY_DC` |
| 电流环给定 | 1 A | `SFRA_IREF_DC` |

都在 `APP/sfra_cfg.h` 里改。

## 四、扫频参数

```c
SFRA_FREQ_LENGTH   48          /* 48 点：100 Hz ~ 2.1 kHz */
SFRA_FREQ_START    100.0f      /* 起始 100 Hz */
SFRA_FREQ_STEP     1.059253f   /* 每十倍频程 40 点 */
SFRA_ISR_FREQ      20000.0f    /* = 开关频率，填错频率轴整体偏移一倍 */
```

**上限不能超过 `fsw/10 ≈ 2 kHz`**。想再多扫几个点可以改成 60 点（到 3 kHz），
但 100 点（31 kHz）已经远超声速采样限制，高频段全是假数据。

## 七、电流内环已改成电感电流

`PI_I.Fdb = IL`（原先是 `ICap = IL - Iout`，两路相减噪声叠加）。

**注意**：`IL` 含 20 kHz 开关纹波，按 SFRA 规范**不能在 ISR 里做软件滤波**再喂给库，
否则会引入相移、模型失真。噪声只能靠硬件 RC 处理。

## 八、保护

`SFRA_ENABLE=1` 时 `Protect_Enable` **强制为 1**（软件过压 45 V / 过流 25 A）。
注入前有故障门（`SFRA_INJ` / `SFRA_COL`），保护一动作就停止注入，避免把故障期的
数据当扫频结果。

硬件 COMP 过流不依赖——台架上 `ADCINA2` 可能没接。

## 九、内存（Flash 版实测）

```
FLASHA    0x1E76 / 0x1F80   （代码，满了会自动spill到 FLASHC）
FLASHC    0x0000 / 0x2000   （备用量 8K 字）
dataRAM1  0x05D8 / 0x0C00   （普通数据）
SFRA_DATA 0x0020 / 0x0400   （库内部数据，0x9C00 起，64 字对齐）
```

`SFRA_IQ_Data` **必须 64 字对齐**，库有要求。已单独划 `SFRA_DATA : origin = 0x009C00`，
0x9C00 ÷ 64 = 624，天然对齐。若改链接脚本，务必确认这一步。

## 十、已知限制

1. OLED 和 SFRA 不能同时用（GPIO28/29 冲突）
2. Flash 版**只靠调试器 Load**，不要求脱机上电自启动（boot 引脚没动）
3. 示波器在两种模式下地址不同，换模式后 Graph 的 Start Address 要重填
