# SPI_LC_iq 接入 SFRA 扫频 + 电流内环改 IL —— 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 F28035 单相逆变器加上 TI SFRA_IQ 扫频（SCI + SFRA GUI），同时把电流内环从电容电流改成电感电流。

**Architecture:** 用 `SFRA_ENABLE` 与三个 build configuration 把"OLED 版"和"SFRA 版"分开；SFRA 版代码从 Flash 运行（RAM 代码空间差约 870 字）。`LOOP_MODE` 统一原来的 `Loop_Mode`，决定注入点/采集点与扫频工作点。电流内环反馈改为单路 `IL`。

**Tech Stack:** TI C2000 F28035、CCS 10.4、CGT 20.2.5（COFF）、IQmath（GLOBAL_Q=24）、SFRA_IQ v1.20、`SciCommsGui_32bit.c` 上位机协议。

**Spec:** `docs/superpowers/specs/2026-10-28-sfra-port-design.md`

## Global Constraints

- C28x 的 `long` 是 32 位、`char` 是 16 位；累加平方必须 `long long`，`x` 先 `>> 8`。
- IQmath 全局 Q 为 24；源码里 `_iq` 字面量必须用 `_IQ()`，禁止裸小数。
- 源码统一 UTF-8；不得引入 GBK 字节。
- 所有 TF/Code 文件的修改只用 edit/write 工具，禁止用 PowerShell 对含中文的文件做文本替换。
- `SFRA_ENABLE` 必须写成 `#ifndef` 包住，允许 build configuration 用 `-d` 覆盖。
- `SFRA_ISR_FREQ` 必须等于 20000.0f（开关频率），不是 40 kHz。
- 扫频上限 2.1 kHz（48 点），不得把 20 kHz 以上频点喂给库。
- 现有 `Debug` 配置（RAM 运行、`SFRA_ENABLE=0`）的行为必须与改动前逐项一致。

## Review Focus

- `SFRA_ENABLE=0` 时 `LOOP_MODE=0` 分支仍走"正弦 + 软启动"，输出与改前一致（任务 1 的回归检查）。
- Flash 版 `main()` 里 `memcpy`+`InitFlash()` 只在 Flash 配置编译，RAM 配置不得引用 `RamfuncsLoadStart`（任务 4 的链接检查）。
- 保护动作时注入必须停止，否则扫频数据全废（任务 7 的故障门检查）。
- `SFRA_IQ_Data` 段实际地址必须能被 64 整除（任务 4 的 map 检查）。
- 参考冻结后输出可能超压：`Vref=20V` 必须限幅在 `Vref_Peak` 以下（任务 6 的限幅检查）。

- [ ] **Step 1: 加工作点常量与限幅**

```c

```

`SFRA_VREF_DC` 使用前必须限幅：`if (vref > Vref_Peak) vref = Vref_Peak;`（Review Focus 第 5 条）。

- [ ] **Step 2: ISR 分支**

- `LOOP_MODE == LOOP_FIXED_DUTY`：`Duty = SFRA_IQ_INJECT(SFRA_DUTY_DC)`，再 `SFRA_IQ_COLLECT(&Duty, &IL)`（或按采集开关切 `&Vout`）
- `LOOP_MODE == LOOP_CURR_CLOSED`：`PI_I.Ref = SFRA_IQ_INJECT(SFRA_IREF_DC)`，`SFRA_IQ_COLLECT(&PI_I.Ref, &IL)`
- `LOOP_MODE == LOOP_VOLT_CLOSED` / `LOOP_DUAL`：`PR_V.Ref = SFRA_IQ_INJECT(SFRA_VREF_DC)`，`SFRA_IQ_COLLECT(&PR_V.Ref, &Vout)`
- 其余（`LOOP_SINE_OPEN`）：保持原样，不注入

**每个 ISR 只能调用一次 INJECT 和一次 COLLECT。**
